# Sumber ikon teknologi

Logo digunakan untuk mengidentifikasi teknologi yang disebutkan pada portofolio. Merek dagang tetap milik pemegangnya.

| Aset | Sumber |
| --- | --- |
| `python.svg`, `java.svg`, `jupyter.svg`, `html.svg`, `css.svg`, `javascript.svg`, `react.svg`, `nextjs.svg`, `nodejs.svg` | [Devicon v2.18.0](https://github.com/devicons/devicon/tree/v2.18.0/icons), MIT |
| `c.svg` | [Devicon v2.16.0](https://github.com/devicons/devicon/blob/v2.16.0/icons/c/c-original.svg), MIT |
| `github.svg` | [GitHub Primer Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg), MIT. Warna putih mengikuti [panduan merek GitHub](https://brand.github.com/foundations/logo). |
| `tableau.svg` | [SVG Logos](https://github.com/gilbarbara/logos/blob/main/logos/tableau-icon.svg), koleksi CC0-1.0 |
| `excel.svg` | [Aset Microsoft Excel](https://static2.sharepointonline.com/files/fabric-cdn-prod_20200430.002/assets/brand-icons/product/svg/excel_48x1.svg) |
| `odoo.svg` | [Odoo Brand Assets](https://www.odoo.com/page/brand-assets). Varian terbalik dengan area pandang disesuaikan dan bentuk serta warna asli dipertahankan. |
| `sql.svg` | Ikon basis data generik untuk portofolio ini. |

Salinan lisensi Devicon, GitHub Primer Octicons, dan SVG Logos disimpan di direktori ini.
